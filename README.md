This is the Live Crypto Terminal program. Below is the installation guide to make the program work.

------------------------------------------------------------------------------
INSTALLATION GUIDE                                                
------------------------------------------------------------------------------

1. Open your command prompt and run these commands one at a time:

pip install flask
pip install requests
pip install feedparser

(Note: sqlite3, time, random, datetime, and os come pre-installed with Python, so you don't need to download them)

------------------------------------------------------------------------------

2. Open your terminal, navigate to your project folder and run "main.py" and app.py".

"cd Desktop > cd { YOUR FILE NAME } > python main.py"
"cd Desktop > cd { YOUR FILE NAME } > python app.py"

(Note: add directory "OneDrive" before "Desktop" if you have OneDrive set up)

------------------------------------------------------------------------------

3. After you have done Step 2, press the internet shortcut link or go to your browser and type in the port link: "http://127.0.0.1:5000/"

------------------------------------------------------------------------------

4. Press " START " and begin the game!
